# Cold Storage Monitor: High-Fidelity Prototype

Clickable prototype of a smart cold storage monitoring system with automated cooling control and machine-learning expiry prediction, designed for grocery store cold rooms (client: DALI Supermarket).

Built with plain HTML, CSS and JavaScript. No install or build step.

## How to run

1. Download or clone this repository.
2. Open `index.html` in any modern browser.
3. On the login screen, click **Fill in demo login**, then **Log in**. Any username and password works.

## Screens (9)

1. Login
2. Home Dashboard
3. Monitoring and Control
4. Inventory
5. Add / Edit Item (form)
6. Review
7. Saved confirmation
8. Expiry Predictions
9. Alerts and Settings

## Main task to try

Dashboard > **Add stock item** > fill in the form > **Review item** > **Confirm and save** > **View in inventory**.

Second task: open **Monitoring**, choose **Produce Chiller**, switch it to **Automatic** mode, and watch the temperature return to range and the alert resolve.

## Notes

- Sensor readings, cooling behavior and the expiry prediction are simulated for this prototype.
- Sample products and storage units are placeholder data.
- Supports light and dark mode and works on phone, tablet and computer.
